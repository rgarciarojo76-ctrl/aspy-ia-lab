# DIRECCIÓN TÉCNICA IA LAB

Portal de acceso a las herramientas de experimentación con Inteligencia Artificial para PRL.

## Estado del Proyecto
*   **Versión**: 1.0.0
*   **Estado**: Producción (Stable)
*   **Identidad**: Dirección Técnica (anteriormente ASPY)

## Características
*   **Seguridad**: Autenticación, Auditoría ENS, CSP, Rate Limiting.
*   **Diseño**: Interfaz "Premium" con tema Dark Blue/Cyan.
*   **Arquitectura**: React + Vite (Modular).

## Instalación

```bash
git clone https://github.com/rgarciarojo76-ctrl/aspy-ia-lab.git
cd aspy-ia-lab
npm install
npm run dev
```
